## Proposed build (each step approved separately)
1. **Palette layer:** a `look` value in the spec (`mono`, `dark`, `colour`) that sets background, wall/floor fills, skin and clothes colours. Code only.
2. **Dark-colour characters:** flat-shaded people (skin, hair, shirt colours, eyes, mouth), the grin face, uniforms (attendant, usher). Code only.
3. **Dark-colour sets:** cabin (fix perspective), cinema hall with screen and seats, hallway, house cutaway - filled with colour and a soft light.
4. **Full-colour sets:** need many more illustrated assets (shelves, store fronts, tanks, classroom). Decide between code-drawn flat illustration and Flow pictures per set; Flow cost applies.
5. **Rule card designs per video** (paper card, hazard stripe, slide-in tag).

Open decision: for full colour, code-drawn flat illustration (free, simpler look) or Flow pictures (richer, costs credits and is unstable today).
