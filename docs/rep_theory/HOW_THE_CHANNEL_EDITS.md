# How the channel places graphics: the Planche video shot by shot (2026-11-02)

All 180 shots of "I'll Prove You Can Do a Planche" (13:06) were looked at and classed, the narration was transcribed with
word times, and every on-screen change was timed against the words. Numbers marked ≈ come from classing shots by eye.
Companion files: [PLAN_NEXT_GRAPHICS.md](PLAN_NEXT_GRAPHICS.md) (what to build) and [ADOPT_GRAPHICS_SHEET.png](ADOPT_GRAPHICS_SHEET.png).

## 1. The mix

| Shot type | Shots | Share of time | Median shot |
|---|---|---|---|
| Code-drawn diagram / card (lever, meters, gauges, graphs, calendars, plan, rules) | ≈77 | **≈43%** | 3.8 s |
| Character picture (the one trainee, ~40 poses, with labels / arrows / rings) | ≈63 | **≈33%** | 3.7 s |
| Art asset (x-ray limbs, shoulder-blade back view, silhouettes, objects, food, scale) | ≈26 | **≈16%** | 4.2 s |
| Progression chain (the spine) | ≈14 | **≈7%** | 3.1 s |

- **The shot type changes about 5 times a minute.** Inside one type, the picture or diagram changes about every 3.8 s, and
  something new lands about every 1 s.
- **On-screen changes are locked to the words:** 476 changes inside shots, median offset to the nearest word start
  **-0.02 s**, and **86% within ±0.25 s**. Things appear *on* the word, a hair early, never late.
- **Runs:** diagrams run up to ~25 shots in a row (the whole physics section), pictures up to ~10 (an exercise unit), art
  assets 2-3, the chain 1-3.

## 2. The mix depends on the section, not on a fixed ratio

| Section (time) | What it is | Dominant shots |
|---|---|---|
| Hook 0:00-0:20 | claim, "I'll prove it", strike-out, lever | hero picture → lever diagram |
| Goal + spine 0:17-0:35 | day 1 fails, goal card, 7 links | picture → chain |
| Test + ask 0:42-0:56 | "lean until… count… comment your number" | pictures with cues + stopwatch, locked result board |
| Product 0:56-1:12 | the 90-day plan | book mockup + chain cards |
| **Why (physics) 1:12-2:28** | load = weight × distance, size vs strength, elite gymnasts | **diagrams almost only** (lever, meters, circle vs cube, graph, silhouettes, height chart, scale) |
| **Units: links 1-7 (2:28-10:38)** | how to do each step | **pictures** (the trainee in the pose with cues on each word), then the number as a token or stopwatch, a study card, and the chain at the start of each unit |
| Warning (link 4, 5:17-7:03) | tendons | x-ray assets, gap graph, hazard tape, rule slots |
| Mistakes 8:48-9:53 | 3 mistakes | numbered cards → picture wrong/right per mistake → ticked list |
| "Like a skill" 10:38-11:35 | how often | calendars, tear-off pages, split circle, battery |
| Plan 11:35-12:18 | the week | clipboard built row by row, holds chain, unlock |
| Result + close 12:18-13:06 | test payoff | result bands → chain → comment mock → callback |

So the rule is **"show what the sentence is about"**: *how to do it* gets a picture of the person doing it, *why it
works* gets a diagram, *what it does inside* gets an anatomy asset, *where you are* gets the chain, *how much* gets a
number device.

## 3. How a sentence becomes a graphic (the channel's grammar)

| Sentence does… | Shown as | Example |
|---|---|---|
| makes a claim that sounds wrong | the claim as a question, then struck out | "A planche isn't a strength trick" |
| explains a mechanism | a diagram that moves as it is said | lever: pivot, bar, weight, distance, load meter |
| names a factor that changes it | the same diagram comes back changed | "+10 kg" → backpack pinned, meter rises |
| compares two sizes / rates | shape or meter pairs | circle vs cube; weight vs strength bars |
| cites research | study card (author, year, sample) + its result drawn | graph, bars, silhouettes with measurements |
| gives a step of a move | the trainee in that pose, one cue per word | ring on the fingers, arrow "push the floor away" |
| names the muscle doing it | anatomy asset with that muscle red | shoulder-blade back view, "SERRATUS" |
| states the target | a token or a big stopwatch with its target | "3 × 15 S", "30 SECONDS" |
| warns | hazard tape, x-ray, red, the risky part glowing | link 4, "STRAIGHT ARMS → TENDONS" |
| lists N rules / mistakes | N slots that fill, and later come back ticked | "3 RULES", "3 MISTAKES" |
| sets the journey | the chain, recalled with state | HAVE IT / YOU / GOAL / UNLOCKED |
| gives time / frequency | calendar devices | tear-off pages, week strip, battery |
| asks the viewer | comment mock / locked board, paid off later | "comment your number" → result bands |

## 4. Spacing and scene changes
- **One idea = one shot ≈ 3-4 s**, re-dressed every ≈1 s (a cue, label, arrow or number on the next stressed word).
- **Hard cuts** between shots with a sound, a **blur dolly** only into the chain / big titles, and **speed lines** for a
  moment of failure or effort.
- **The same picture holds across the cues of one step** (the trainee stays, the cues change), then cuts on the next step.
- **Unit opener:** the chain zooms to the link, "LINK N" and its name, then the first pose.
- **The words sit in the free side**: small white lead-in + big coloured key word (red warning, green right, orange or
  yellow key). The section label is always top-left, and a safety chip sits bottom-left during every exercise unit.

## 5. How we get ahead (on top of everything we already have)

What we already do better than the reference, and keep: 3D muscle clips, the automatic red reveal and re-framing on
pictures, a new picture per moment from Flow, the music bed + sound mix to -14 LUFS, word-synced cards, the plan-only
quality gate, channel memory so videos don't open alike, and every graphic triggered by sentence shape.

To match the reference and go past it:
1. **A section-aware director.** Classify each part of the script (hook, why, unit / how-to, warning, mistakes,
   frequency, plan, result, close) and pick looks by section: the how-to units lean on pictures with cues, the why parts
   on diagrams, the warning on anatomy assets, the plan and result on cards. Today the mix is one global rotation.
2. **A spine for every video.** When the script has units (links, levels, moves, phases, days), build the chain from
   them and bring it back at every unit, in the result and at the end, with state (done, current, locked, warning, you).
3. **Visual memory.** A device that explains a mechanism comes back changed when a later sentence changes a factor (the
   lever with the backpack, the meter rising). Rules and mistakes come back ticked. The opening picture comes back at the
   end.
4. **Cue density on how-to pictures:** one cue per instruction word on the same pose (ring, arrow, label, line), at
   least 3 per step, as in links 1-3.
5. **CSV v2.** Add a `section` column (hook / why / unit / warning / mistakes / plan / result / close) and a `graphic`
   column (see PLAN_NEXT_GRAPHICS.md section 4). The script prompt teaches the blueprint seen in both videos (claim →
   proof device → goal → spine → test → why → units → warning → mistakes → frequency → plan → result → callback).
6. **Flow, used more and better.** Per video: the trainee in every how-to step, before/after pairs, the hook hero.
   Once, kept forever: anatomy assets (x-ray limbs, back views, brain), objects and mockups. Always with the code
   drawing the text, numbers and motion on top. The coverage report shows which assets and devices new scripts still
   lack.
7. **Never lose anything.** The feature count check fails any change that drops an existing graphic; every addition is
   one more option, previewed by me before it is committed.
